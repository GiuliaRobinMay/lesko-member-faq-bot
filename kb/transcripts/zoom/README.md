# Zoom class transcripts — Lesko Help account

Source: Lesko Help Zoom account, cloud recordings, **1 July 2026 onwards only**.

## Rules applied
- Nothing before 1 July 2026.
- **Team meetings excluded**: New Host Meeting, Staff Meeting with Matthew, Host Meeting.
  Note: "Staff Meeting with Matthew" is a team meeting. "MATTHEW MEETUP" is a member
  class and is a different thing — it is not in this account.
- Each recording can contain several transcript objects (false starts, setup chatter).
  Only the largest is kept; fragments under 3,000 characters are discarded.
- Topics are matched by `recording_id`, not by date — several classes share a date.

## Regenerating
`zoom_inventory.json` holds the catalogue; `fetch_list.json` holds the double-encoded
UUIDs used with `get_recording_resource`. Re-run those to refresh.

## Not available from this account
Application Classes, Drop-In Clinic, Open Office, Matthew Meetup, Thursday/Saturday/
Sunday Q&A with Tony, Business Growth (Amber), Start a Nonprofit, Call Sheet Classes.
These sit under individual hosts' Zoom accounts. Admin-level access, or each host
granting access, would be needed.

## Privacy
These transcripts contain members' real names and personal circumstances. Mine them
for patterns and phrasings; do not copy personal details into the bot's answers.
